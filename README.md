Sample POS System
The project shows a sample of a POS System using CodeIgniter4.

Setup and Run
1. Clone the repository: git clone https://github.com/ashirii20/IT0049-WEB-SYS.git
2. Open the project folder: cd tfa1
3. Install dependencies: composer install
4. Configure the .env file and set: app.baseURL = 'http://localhost:8080/'
5. Run the application: php spark serve
6. Open a browser and go to: http://localhost:8080

Available Pages
- / - Landing Page
- /about - About Page
- /customers - Customer Accounts
- /users - User Accounts
